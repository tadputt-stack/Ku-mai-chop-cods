# Free2Pay 🎨💼

> **"พื้นที่ของคน 'free' แลนซ์"**  
> แพลตฟอร์มคอมมูนิตี้และพื้นที่จัดแสดงผลงานสำหรับฟรีแลนซ์ นักวาด ศิลปิน และผู้ว่าจ้าง

---

## 📌 เกี่ยวกับโปรเจกต์ (About Project)

**Free2Pay** เป็นเว็บไซต์แพลตฟอร์มสำหรับฟรีแลนซ์และสายผลิตงานศิลปะ (Digital Art, Design, Illustration) ที่ช่วยเชื่อมต่อระหว่าง **ผู้ว่าจ้าง (Clients)**, **ศิลปิน (Artists)** และ **แฟนคลับ (Fans)** ให้สามารถเข้าถึงผลงาน พูดคุย ให้ฟีดแบ็ก และจ้างงานได้อย่างสะดวกสบาย

---

## 📂 โครงสร้างโฟลเดอร์ (Project Structure)

```text
free2pay/
├── css/              # โฟลเดอร์เก็บไฟล์ตกแต่งสไตล์ (CSS)
├── images/           # รูปภาพ โลโก้ และไอคอนประกอบเว็บไซต์
├── page/             # หน้าเว็บ HTML ต่างๆ
│   ├── index.html    # หน้าแรก (Home Page)
│   ├── search.html   # หน้าค้นหาผลงานและหมวดหมู่งาน (Search)
│   ├── live.html     # หน้าการไลฟ์สดและตารางกิจกรรม (Live & Calendar)
│   ├── login.html    # หน้าเข้าสู่ระบบ (Login)
│   └── profile.html  # หน้าโปรไฟล์ผู้ใช้งาน (Profile)
└── README.md         # เอกสารแนะนำโปรเจกต์
```

---

## ✨ ฟีเจอร์หลัก (Key Features)

- **Portfolio & Artwork Showcase**: พื้นที่โชว์ผลงานแบบโฟลเดอร์แฟ้มและแกลเลอรี
- **Community Feed & Post Note**: การ์ดสร้างโพสต์และกระดานอัปเดตผลงานใหม่
- **Artist Feedback System**: ระบบคอมเมนต์รีวิวและให้คะแนนผลงานศิลปิน
- **Multi-Role Categories**: แบ่งหมวดหมู่การใช้งานชัดเจนสำหรับผู้ว่าจ้าง ศิลปิน และผู้ติดตาม

## 🚀 วิธีการเปิดใช้งาน (Getting Started)

1. Clone หรือ Download Repository นี้:
   ```bash
   git clone https://github.com/saengkaewt-source/free2play.git
   ```
2. เปิดไฟล์ `page/index.html` บนเว็บเบราว์เซอร์ (Chrome, Edge, Safari, Firefox) หรือใช้ส่วนขยาย **Live Server** ใน VS Code เพื่อดูตัวอย่างเว็บไซต์
